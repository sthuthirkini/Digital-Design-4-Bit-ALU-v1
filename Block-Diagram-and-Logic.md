## How the 4-Bit Adder/Subtractor Works

The `add_sub` module performs both addition and two's complement subtraction using a ripple-carry chain built from four 1-bit full adders. Each full adder computes the standard 3-input sum:

$$\text{Sum} = A + B_{\text{modified}} + C_{\text{in}}$$

Depending on the state of the `SUB` control signal, the hardware dynamically switches between addition and subtraction:

### 1. Addition (`SUB = 0`)
* **Carry-In:** `carry[0] = SUB` evaluates to `0`.
* **Operand B:** `B_modified = B ^ {4{SUB}}` evaluates to `B ^ 4'b0000 = B` (unchanged).
* **Operation:** The circuit computes:
  $$Y = A + B + 0$$
  This performs standard binary addition ($A + B$).

### 2. Subtraction (`SUB = 1`)
* **Carry-In:** `carry[0] = SUB` evaluates to `1`.
* **Operand B:** `B_modified = B ^ {4{SUB}}` evaluates to `B ^ 4'b1111 = \sim B` (bitwise negation/inverted $B$).
* **Operation:** The circuit computes:
  $$Y = A + \sim B + 1$$
  Since adding the inverted bits plus $1$ is the definition of two's complement negation ($\sim B + 1 = -B$), this successfully transforms the addition chain into subtraction:
  $$Y = A - B$$

> **HDL Bitwise Equivalence:** 
> The statement `assign B_modified = B ^ {4{SUB}};` is the concise hardware description language (HDL) equivalent of saying: *“If `SUB` is 0, keep `B_MODIFIED` equal to `B`; if `SUB` is 1, invert `B` so that `B_MODIFIED = ~B`.”*

### The Architecture: Why a 5-Bit `carry` Vector?

In this design, `carry` is intentionally declared as an internal 5-bit signal (`logic [4:0] carry`) rather than using multiple standalone wire declarations. 

* **Cleaner Code & Simplified Wiring:** Declaring a vector avoids the clutter of creating multiple separate internal wire names to connect the carry-out of one full adder to the carry-in of the next. It allows clean, systematic indexing for each bit stage.
* **Role Breakdown of the 5 Carry Bits:**
  * **`carry[0]`**: Holds the carry-in of the first adder, which is driven directly by the `SUB` control signal.
  * **`carry[3:1]`**: The three bits in between act as the intermediate link signals passing the carry state between adjacent full adders.
  * **`carry[4]` (MSB)**: Holds the final carry-out (`Cout`) generated by the last full adder.
* **A Bundle of Convenience:** Because these carry bits are never processed together as a single 5-bit numerical value, treating them as a vector is simply a convenient hardware design pattern to group related physical wires together.
